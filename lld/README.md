# Low-Level Design (LLD)

Classic system design problems implemented small and runnable. Every lab starts with `DESIGN.md`.

## Planned labs

| Lab | Focus |
|-----|-------|
| `rate-limiter` | Token bucket, Redis, multi-instance |
| `url-shortener` | Hashing, read-heavy DB design |
| `parking-lot` | OOP modeling, state machines |
| `notification-system` | Queues, fan-out, retries |
| `task-queue` | Workers, visibility timeout, DLQ |
