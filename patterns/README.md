# Patterns

Reusable building blocks organized by language. Not full apps — composable modules you can lift into projects.

```
patterns/
├── python/    # e.g. repository pattern, dependency injection
├── go/        # e.g. middleware chain, graceful shutdown
└── node/      # e.g. error handling, request validation
```

Add patterns as you encounter them in real work. One pattern per subfolder with a short README.
